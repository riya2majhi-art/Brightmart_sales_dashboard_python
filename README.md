# 📊 BrightMart Sales Dashboard

An interactive Sales Dashboard built using Streamlit, Python, Pandas, and Plotly. This dashboard helps analyze sales performance through KPIs, charts, and interactive filters.

## 🚀 Features

- Sales Overview Dashboard
- Revenue & Profit KPIs
- Customer Analysis
- Product Performance
- Category-wise Sales
- Monthly Sales Trend
- Interactive Filters
- Responsive Streamlit Interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- OpenPyXL

## 📂 Dataset

The dashboard uses the following datasets:

- Customers
- Orders
- Order Items
- Products

## 📁 Project Structure

```
app.py
data_loader.py
requirements.txt
customers.csv
orders.csv
order_items.csv
products.csv
```

## ▶️ Run Locally

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
